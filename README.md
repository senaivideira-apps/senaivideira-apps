Organização que reúne os projetos desenvolvidos nas aulas dos cursos de
formação técnica e de aprendizagem em tecnologia do **SENAI Videira**.

Aqui ficam os trabalhos práticos, projetos integradores e atividades
aplicadas em sala — do primeiro contato com lógica de programação até
sistemas web completos com banco de dados e integração de hardware.

---

## Sobre

Este espaço existe para dar visibilidade ao trabalho dos alunos e ao
processo de aprendizagem: cada repositório registra um projeto real,
aplicado em aula, com sua documentação, equipe e tecnologias utilizadas.

Os projetos são orientados pelos professores da área de Sistemas de
Informação e ficam documentados para consulta de alunos, turmas futuras
e da comunidade.

## Cursos atendidos

### Técnico em Desenvolvimento de Sistemas

Formação técnica voltada ao desenvolvimento de software, com base em
lógica de programação, orientação a objetos, banco de dados, APIs,
aplicações web e mobile, além de projetos integradores que simulam
demandas reais do mercado.

### Aprendizagem em Programação de Sistemas de Informação

Curso de formação inicial para o primeiro emprego na área de tecnologia.
Parte da lógica de programação e introdução ao desenvolvimento web,
chegando à construção de sistemas com o uso de ferramentas profissionais
de mercado, versionamento de código e trabalho em equipe.
